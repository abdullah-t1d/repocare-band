# repoCare Band web app

Flutter Web app that replaces the prototype [dashboard](../dashboard/): live readings and guided measurements from the repoCare Band.

> Work in progress. Full documentation is added at the end of development.

```bash
flutter pub get
flutter test
flutter run -d chrome
```

Non-diagnostic graduation prototype. The bundled IBM Plex Sans Arabic fonts are licensed under the SIL Open Font License ([assets/fonts/OFL.txt](assets/fonts/OFL.txt)).
